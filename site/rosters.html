How every number on this page is derived
Built by scripts/build-roster-room.mjs from the ten live Sleeper rosters, priced with the same league-scored projections the draft board uses; wins and points for come live from the Sleeper API. Strength is a recomputed optimal lineup, not a ranking; trade proposals ship only where both lineups rise. Owner tendencies come from league-tendencies.md and six seasons of raw transactions. Player dossiers are published by scripts/build-player-news.mjs. Nothing here is written by the page — it renders published JSON and shows an explicit error when that JSON is missing.
