Paste a Sleeper league id above and hit connect. The id is the long number in the league's Sleeper URL — sleeper.com/leagues/1234567890123456789/team — and pasting the whole URL works too.

It is remembered in this browser, so the tab opens on the same league next time. ?league=<id> in the address bar overrides it for one visit.

Everything on this page is read live from the Sleeper public API for the league you connect, and is scored and shaped by that league's own settings. This project's valuation, FAAB pricing, trade search and owner dossiers are built for the HBGBs and are deliberately not applied here. Nothing is ever written back to Sleeper.
